# Interactive Personal Website

## Files
- index.html = login page
- home.html = protected interactive webpage
- style.css = responsive design and animations
- script.js = login, menu, theme, counter, scroll reveal and form interactions
- assets/profile.png = your uploaded picture

## Run
1. Keep the folder structure unchanged.
2. Open `index.html` in a browser.
3. Login with any username and password `1234`.
4. You will be sent to `home.html`.

## Videos
The two YouTube videos are examples. Replace their iframe URLs with your own YouTube embed URLs.

For an MP4:
1. Put your file in `assets/`.
2. Rename it to `my-video.mp4`, or change the filename in `home.html`.

## Important
This is a front-end/demo login. The password is visible in JavaScript, so it is NOT suitable for real accounts or sensitive information. For a real website, use a server/backend for authentication.
